# 🌾 Rento Krishi Share

An intelligent agriculture platform that connects farmers with agricultural equipment rental services, transportation, AI-powered crop advisory, weather updates, and shared booking optimization.

Built with a modern tech stack, the platform helps farmers access farming resources efficiently while reducing operational costs through technology.

# ⚙ Installation

Clone the repository

```bash
git clone https://github.com/varshi99/rento-krishi-share.git
```

Navigate to the project

```bash
cd rento-krishi-share
```

Install dependencies

```bash
npm install
```

Start the development server

```bash
npm run dev
```

Build for production

```bash
npm run build
```

Preview production build

```bash
npm run preview
```

---

# 🔐 Environment Variables

Create a `.env` file and configure:

```env
VITE_SUPABASE_URL=your_supabase_url
VITE_SUPABASE_ANON_KEY=your_supabase_anon_key

RAZORPAY_KEY_ID=your_key
RAZORPAY_SECRET=your_secret

WEATHER_API_KEY=your_weather_api_key
```
